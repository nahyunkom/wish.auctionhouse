# 소망생물 픽셀 움직임 — 2026-10-26

- 수족관에만 픽셀 단위의 부드러운 변위를 적용한다. 진단 메인 그래픽, 원본 PNG/영상과 결과 매핑은 바꾸지 않는다.
- WebGL fragment shader가 표시 좌표를 다시 샘플링한다. 기본 변위는 화면 기준 최대 2.6px, 느린 호흡 성분을 더해 통상 약 1~3px의 미세 변화가 난다.
- 2차원 물결을 겹치고 중심에서 바깥으로 갈수록 강하게 반영한다. 부위별 의미 인식·실제 관절 움직임은 아니다.
- 원본 색과 alpha를 사용하는 premultiplied-alpha 합성. 파랑 바다의 기존 조명/스크린 합성도 유지.
- 한 프레임 텍스처 업로드 최대 2개, GPU 캐시 최대 128개. 로딩 대기·WebGL 미지원·context lost 시 기존 Canvas 표시를 사용한다.
- prefers-reduced-motion이면 생물의 유영·회전·픽셀 변형을 멈춘다.
- 장시간 재생 시 시간 값 순환을 모든 물결의 공통 주기에 맞춰 경계에서 튀지 않도록 했다.
- 기존 실루엣/원본 RGB·alpha 검사 및 신규 GPU 리소스·복구 검사 통과.
- 실제 원본 생물 1종의 표시용 복사본으로 EGL/OpenGL ES shader 검증: highp/mediump 컴파일 성공, 36,101 표시 픽셀, 시간에 따라 35,695 픽셀 값 변화, 원본 바이트 보존, reduced-motion 정지, 주기 경계의 채널 차이 최대 2/255, GL 오류 0.
- 이는 화면 픽셀의 연속적인 미세 변형이며 픽셀아트 스타일이나 매 픽셀을 CPU에서 반복 처리하는 방식은 아니다.
