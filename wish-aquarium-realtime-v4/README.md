# 소망경매장 — 실시간 공유 수족관

관람객이 모바일에서 소망을 진단하고, 결과 생물을 이미지로 간직하거나 전시장 빔프로젝터의 공유 수족관에 실시간으로 방류하는 전시용 웹 프로젝트입니다.

## 포함된 화면

- `/` — 관람객용 모바일 진단 사이트
- `/shared-aquarium` — p5.js 기반 빔프로젝터용 공유 수족관
- `/health` — 서버 동작과 현재 생물 수 확인

관람객이 `공유 수족관에 방류하기`를 누르면 Socket.io 서버가 생물의 두 분류값을 검증한 뒤 모든 공유 수족관 화면에 즉시 전달합니다. 진단 답변은 서버에 저장하지 않으며, 방류된 생물 정보도 기본 6시간 동안 메모리에만 유지됩니다.

## 바로 실행하기

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

실행 후 다음 주소를 엽니다.

- 관람객용: `http://localhost:3000`
- 빔프로젝터용: `http://localhost:3000/shared-aquarium`

빔프로젝터 화면의 `전체 화면` 버튼 또는 키보드 `F`를 누르면 브라우저 전체 화면으로 전환됩니다.

## 전시장 배치

가장 안정적인 구성은 관람객용 사이트와 Socket.io 서버를 같은 Node.js 서비스에 함께 배포하는 것입니다. 이 경우 `config.js`의 `socketUrl`은 빈 값으로 유지합니다.

```text
관람객 휴대폰 ─┐
관람객 휴대폰 ─┼─ Socket.io 서버 ─ 빔프로젝터 브라우저
관람객 휴대폰 ─┘
```

배포된 기본 주소를 전시장 QR코드로 만들고, 빔프로젝터 PC에서는 같은 주소 뒤에 `/shared-aquarium`을 붙여 엽니다.

## 웹사이트와 서버를 분리할 때

정적 웹사이트를 별도 주소에 두는 경우 `config.js`에 Node.js 서버의 HTTPS 주소를 입력합니다.

```js
window.WISH_AQUARIUM_CONFIG = {
  socketUrl: 'https://your-socket-server.example.com',
  connectionTimeoutMs: 8000
};
```

서버 환경 변수에는 관람객용 사이트 주소를 등록합니다.

```bash
CLIENT_ORIGINS=https://your-static-site.example.com
```

두 주소를 쉼표로 구분하면 여러 출처를 허용할 수 있습니다. 실제 휴대폰 접속에는 HTTPS 주소가 필요합니다.

## 환경 변수

| 이름 | 기본값 | 용도 |
| --- | ---: | --- |
| `PORT` | `3000` | Node.js 서버 포트 |
| `CLIENT_ORIGINS` | 같은 주소만 | 분리 배포 시 허용할 웹사이트 주소 |
| `CREATURE_TTL_MS` | `21600000` | 방류 생물 유지 시간, 기본 6시간 |
| `MAX_CREATURES` | `120` | 동시에 유지할 최대 생물 수 |

서버를 재시작하면 공유 수족관은 비워집니다. 전시 회차별 초기화가 필요할 때 서버를 재시작하면 됩니다.

## 결과 이미지 저장 방식

결과 화면의 `내 생물 이미지 저장하기`는 1080×1920 PNG 카드를 브라우저에서 직접 생성합니다. 모바일에서는 운영체제의 저장·공유 창을 열고, 지원하지 않는 브라우저에서는 PNG 파일을 바로 다운로드합니다. 이메일 주소 같은 개인정보는 수집하지 않습니다.

## GitHub에 올리기

압축을 푼 이 폴더 안의 파일을 저장소 최상위에 올립니다. `.openai/`, `node_modules/`, `.env`는 `.gitignore`에 포함되어 GitHub에 올라가지 않습니다. 배포 서비스의 시작 명령은 `npm start`로 설정하면 됩니다.
