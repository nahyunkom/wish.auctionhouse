- 방류·저장 도중 다른 화면으로 이동해도 다음 관객의 결과에 늦은 응답이 섞이지 않도록 보완했다.

## 검증
npm run check: 원본 매핑·해시·원본 저장·기존 수족관 렌더링·신규 체험 흐름·입력 문자열 escaping·재시작 초기화·실제 방류 집계·빈 기록/오프라인 안내 검사.
이 검사는 VM DOM harness 및 데이터/정적 검사다.
로컬 Node 서버 기동은 확인했으나 실행 환경의 소켓 접근 제한으로 HTTP 요청은 불가했다.
브라우저 연결 실패 및 Windows 앱 접근 승인 시간초과로 이번 시각 검수·실제 터치 검수는 완료하지 못했다.
첨부 참고 이미지는 Library 읽기 결과의 추출 텍스트를 확인했으나 이미지 원본 materialize가 접근 오류로 실패했다. 전체 이미지를 시각 검수했다고 주장하지 않는다. 사용자 제공 15단계 목차를 흐름의 주된 참고로 삼았다.
실제 iPad Safari에서 레이아웃·드래그·영상·원본 저장·다중 기기 방류 검수가 필요하다.
